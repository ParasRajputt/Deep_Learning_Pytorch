# Titanic EDA — My First Data Analysis Project

This is my first attempt at doing an Exploratory Data Analysis (EDA) on the classic Titanic dataset. I wanted to get comfortable with pandas, handling missing data, and making simple visualizations.

---

## What I did

- Loaded the training and test datasets
- Checked for missing values and cleaned the data
- Explored survival rates based on gender, passenger class, and age
- Made some basic bar charts and line plots to visualize the findings

---

## What I found

- Women had a much higher survival rate than men
- 1st class passengers survived at a significantly higher rate than 3rd class
- Age had a more varied effect on survival

---

## Tools used

- Python
- pandas
- numpy
- matplotlib
- Jupyter Notebook

---

## Dataset

The dataset used is the [Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic/data) dataset from Kaggle.

---

## How to run

1. Clone this repo
2. Download `train.csv` and `test.csv` from Kaggle and place them in the same folder
3. Open `Titanic_EDA.ipynb` in Jupyter Notebook and run all cells
